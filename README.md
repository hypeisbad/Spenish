# 🌮 Spenish — Español de México

An all-in-one **Mexican Spanish translator and learning app** with a dark *Noche de Cempasúchil* theme.
It's an installable, offline-capable web app (PWA) that runs on phones, tablets and desktops.

## What's inside

### Translate & communicate
- **Translator**: English ↔ Mexican Spanish with auto-detect, voice input, Mexican (es-MX) text-to-speech, a slow 🐢 mode, history and favorites.
  - **Four engines with automatic fallback**: Claude AI → Google → MyMemory (es-MX) → a built-in offline dictionary.
  - **“Verificar”** back-translates the result so you can check the meaning.
  - **Mexico hints** flag Spain-only words (coche → *carro*, ordenador → *computadora*, coger → *agarrar* ⚠️).
  - **Slang detector** explains any Mexican slang in your text, with a spice level 🌶️.
  - **AI mode** (optional) lets you pick a register (neutral, casual, slang, formal) and adds alternatives, a literal gloss and cultural notes.
- **Face-to-face interpreter**: split screen, with the top half rotated 180° for the person across the table. Each person taps their mic, and the translation is spoken aloud.
- **Scan & translate**: photograph a menu or sign. With an AI key, Claude reads it and explains unfamiliar dishes; without one, on-device OCR extracts and translates the text.
- **Tap any word, anywhere**: you get its meaning, a speak button, a save-to-deck button, and *verb analysis* (“fuimos” → ir/ser · preterite · nosotros).

### Learn
- **Course**: 16 units and 66 lessons, covering 250 words and 85 sentences, all in Mexican usage. Exercises include multiple choice, listening, typing (accent-tolerant), matching pairs, sentence building and speaking. Combos, stars and XP are built in, and learned words flow into your flashcard deck.
- **Spaced-repetition flashcards** (SM-2): Spanish→English, English→Spanish and audio-only modes, with interval previews and keyboard shortcuts.
- **Conjugator**: 154 verbs, 13 tenses plus the imperative, generated by a rule engine verified by hundreds of unit tests.
  - Irregular forms are highlighted automatically.
  - Reflexive commands carry correct written accents (*levántate, sentémonos*).
  - *Vosotros* is hidden by default, since Mexico uses *ustedes*.
  - Includes a built-in conjugation drill.
- **Sentence lab**: pick a subject, verb, tense, negation and question form, and get a grammatically correct Spanish sentence with a matching English one.
- **Grammar guides**: 11 topics (ser/estar, por/para, preterite/imperfect, subjunctive, Mexican diminutives…), each with audio examples and a quiz.
- **Pronunciation coach**: speech recognition tuned to es-MX scores you word by word. Includes a Mexican sound guide, tongue twisters and Nahuatl place names.

### Practice & play
- **Profe Lupita, the AI tutor** (optional, Claude): free conversation at your level with gentle corrections on every message; role-play scenes (taquería, taxi, market haggling, pharmacy, a party in Coyoacán); “Explícame” grammar Q&A; and “Corrígeme” text correction.
- **Offline role-plays**: branching dialogues you can answer by tapping or speaking. No key needed.
- **Games**:
  - **Lotería**, with a singing caller and the traditional verses, plus two bots racing you.
  - **Memorama**, a memory-pairs game.
  - **Lluvia de palabras**, where you type translations before words hit the ground.
  - **¿Cuánto cuesta?**, where you listen to prices, numbers and times.
  - **Conjugación relámpago**, a 60-second verb sprint.
- **Stories**: 6 original graded stories with karaoke-style read-aloud, tap-to-translate and comprehension quizzes.

### Reference & tools
- **Phrasebook**: 121 practical phrases.
- **Mexicanismos**: 63 slang terms with a 🌶️ spice meter and regional tags, plus a 38-entry Mexico vs. Spain table.
- **Culture**: cards on customs and history, a live holiday calendar (Easter-based dates are computed), and a countdown on the home screen.
- **Tools**:
  - Numbers in words (*veintiún mil*, *un millón de pesos*).
  - Live peso ↔ dollar converter.
  - Tip splitter.
  - Mexican-style time telling (*cuarto para las ocho*).
  - Dates.
  - Metric conversions.
- **Dictionary**: searches every word in the app in both directions, and understands conjugated verbs.

### Everywhere
- A live **Mexico City clock in Spanish words** on the home screen.
- XP, levels (*Turista* → *Chilango honorario* → *Leyenda*), streaks, a daily goal ring, an activity heatmap, and 21 achievements.
- A **command palette** (⌘K / Ctrl+K / `/`) to jump anywhere or translate anything.
- **Immersion mode** hides the English helper labels.
- Four accent themes.
- Synthesized sound effects (including a mariachi-style fanfare), confetti and haptics.
- Export and import of your progress.

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/
npm run preview    # serve the build at http://localhost:4173
```

Requires Node 18 or newer (CI uses Node 22).

## The AI features (optional)

Open **Ajustes → Inteligencia artificial**, paste an Anthropic API key (get one from [console.anthropic.com](https://console.anthropic.com/settings/keys)) and press **Guardar y probar**.

- The key is stored **only in your browser** and is sent only to `api.anthropic.com`. Usage is billed to your Anthropic account.
- The default model is **Claude Opus 5.5**. You can switch to Sonnet 5.5 or Haiku 5.5 in Settings.
- Requests use low effort for fast replies, stream responses for the tutor, use structured JSON output for translations, and enable server-side refusal fallback.

Everything else works without a key.

## Deploying (GitHub Pages)

`.github/workflows/deploy.yml` builds and deploys on every push to `main`. You need to do one thing first: in the repo, go to **Settings → Pages → Source** and choose **GitHub Actions**.

The app uses relative paths and hash routing, so it also works on any static host (Netlify, Vercel, Cloudflare Pages, S3…).

## Browser support

| Feature | Chrome / Edge | Safari (iOS & macOS) | Firefox |
|---|---|---|---|
| Everything visual, lessons, games | ✅ | ✅ | ✅ |
| Spanish text-to-speech | ✅ | ✅ (Paulina, es-MX) | ✅ |
| Voice input & pronunciation scoring | ✅ | ✅ | ❌ (you can type instead) |

For the most natural Mexican voices, use Edge on Windows (“Dalia” and “Jorge”, Natural) or Safari on iOS (“Paulina”). You can pick a voice in **Ajustes → Voz**.

## Testing

```bash
npm test           # 476 unit tests: conjugation tables, numbers, time, answer checking, SRS, lesson generator
npm run typecheck
npm run build && npm run preview &
npm run smoke      # visits all routes in Chromium and fails on any console or page error
npm run e2e        # interactive flows against mocked network
```

`npm run e2e` drives these flows: onboarding, translator fallbacks, a full lesson, flashcards, games, the command palette, settings, the AI tutor against a mocked Claude stream, and mobile overflow.

## Project structure

```
src/
  lib/          conjugation engine, numbers, time, text utils, SRS, speech, translation, Claude client, store
  data/         course units, verbs, phrases, slang, stories, grammar, culture, lotería, scenarios, lexicon
  components/   UI kit (speak/mic buttons, tap-to-translate, modals), shell effects, command palette
  views/        one file per screen (+ games/)
tests/          vitest suites
scripts/        icon renderer, smoke & e2e browser tests
```

All progress lives in `localStorage`; there is no backend.
